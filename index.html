SubAssist

Privacy Policy
Last updated: October 24, 2026

SubAssist ("we", "our", "the app") is developed by SubSave Studio (studio.subsave@gmail.com). This Privacy Policy explains what data the app accesses, how it is used, and your rights.

1. Data We Access

📁 Files and Media

SubAssist can read file metadata (names, sizes, modification dates) from your device storage to perform storage audits — finding duplicates and large files. Files are processed entirely on-device and never uploaded anywhere.

📱 Installed Applications

The app reads the list of installed applications and their declared permissions to generate a security audit report. This data stays on your device.

🔔 Notifications (optional)

If you grant Notification Listener access, SubAssist reads the sending app and the title and text of each incoming notification. This is done only in device memory, to match them against a built-in list of subscription-related apps and keywords. Notification content is never stored or transmitted.

⏱ Usage Statistics (optional)

With your permission, the app reads Android UsageStats to show screen-time summaries. This data is only displayed to you and never leaves your device.

🤖 AI Provider (optional)

If you choose a cloud AI provider (Gemini, Claude, OpenRouter), your chat messages are sent to that provider's API. To give device-specific advice, the request also includes a short device status summary: device model, Android version, storage and RAM usage, battery level, temperature and charging state, and the number of installed apps (no app names, files or personal identifiers). This happens only after you enable "Send data to AI provider" in Settings → Privacy & Access, and you can turn it off at any time. We do not store these messages on our servers. Please review the privacy policy of the AI provider you select.

If you use the on-device Gemma model, no data is sent anywhere.

⬇️ On-device Model Download (optional)

If you choose the on-device Gemma model, the app downloads the model file from huggingface.co. Hugging Face receives your IP address and technical request data, and the access token only if you enter one for gated models. No chat messages or device data are sent during the download, and after it finishes the model runs fully offline.

🛡️ Fraud Shield — QR & URL Scanning

When you scan a QR code, the app checks the URL against on-device heuristics and, if configured, the Google Safe Browsing API to detect malicious or phishing links. The scanned URL is sent to Google for this check; no other data (device identifiers, personal information) is included. Scan results are stored locally on your device.

📶 Fraud Shield — Wi-Fi Network Protection (optional)

If you enable "Wi-Fi network protection" in Settings, SubAssist reads the name (SSID) and identifier (BSSID) of the Wi-Fi network you connect to, to warn you about possible spoofed access points ("evil-twin" attacks). Android requires precise location permission to read this information, but the app does not determine, store, or transmit your geographic location. This feature is off by default and only activates if you explicitly turn it on.

2. Data We Do NOT Collect

  • We do not collect personal information (name, email, phone number)
  • We do not use advertising SDKs or analytics trackers
  • We do not sell your data. Data is sent to third parties only to the services you choose or enable, as described in Sections 1 and 5
  • We do not store your files or media on any server
  • We do not use GPS or determine your geographic location. The optional Wi-Fi network protection feature only reads the Wi-Fi network name/identifier, not your coordinates (see Section 1)

3. API Keys

If you enter an API key for a cloud AI provider, it is stored locally on your device in the app's private storage, encrypted with AES-256-GCM using a key held in the Android Keystore. It is sent only to the provider it belongs to, over HTTPS, and is never transmitted to SubSave Studio's servers.

4. Permissions Explained

  • READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE (Android 12 and lower) / WRITE_EXTERNAL_STORAGE (Android 10 and lower) — storage audit: listing file names, sizes and dates to find duplicates and large files
  • PACKAGE_USAGE_STATS — screen time statistics (user must grant manually)
  • BIND_NOTIFICATION_LISTENER_SERVICE — subscription detection via notifications (optional)
  • INTERNET / ACCESS_NETWORK_STATE — cloud AI providers, Google Safe Browsing and the on-device model download
  • POST_NOTIFICATIONS — local notifications, e.g. when the SubSave app becomes available on your device (only if you ask to be notified)
  • RECEIVE_BOOT_COMPLETED — restores that optional notification request after the device restarts
  • CAMERA — Fraud Shield QR code scanning
  • ACCESS_WIFI_STATE — Fraud Shield Wi-Fi network protection (optional)
  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — required by Android to read the Wi-Fi network name for Fraud Shield's optional protection feature; not used to determine your location (user must enable manually in Settings)

5. Third-Party Services

SubAssist may optionally connect to the following external AI APIs based on your choice:

  • Google Gemini API
  • Anthropic Claude API
  • OpenRouter
  • Google Safe Browsing (Fraud Shield QR/URL scanning)
  • Hugging Face (one-time download of the on-device Gemma model)

AI provider connections occur only when you send a message in the AI chat. Safe Browsing is contacted when you scan a QR code, and Hugging Face only when you download the model.

6. Data Retention, Security and Deletion

Everything SubAssist stores (settings, scan history, known Wi-Fi networks, the encrypted API key and the downloaded model) stays in the app's private storage on your device. We keep no copy and have no accounts. You can delete all of it at any time by clearing the app's storage in Android Settings → Apps → SubAssist, or by uninstalling the app. Network requests use HTTPS. Messages already sent to an AI provider are held by that provider under its own policy, and we cannot delete them for you.

7. Children's Privacy

SubAssist is not directed at children under 13. We do not knowingly collect any information from children.

8. Changes to This Policy

We may update this policy from time to time. The updated version will always be available at this URL. Continued use of the app after changes constitutes acceptance.

9. Contact

Questions about this Privacy Policy? Contact us at:
studio.subsave@gmail.com

Политика конфиденциальности
Последнее обновление: 24 октября 2026 г.

SubAssist («мы», «наш», «приложение») разработано SubSave Studio (studio.subsave@gmail.com). В этой Политике конфиденциальности объясняется, к каким данным обращается приложение, как они используются и какие у вас есть права.

1. Данные, к которым мы обращаемся

📁 Файлы и медиа

SubAssist может читать метаданные файлов (названия, размеры, даты изменения) из памяти вашего устройства для аудита хранилища — поиска дубликатов и крупных файлов. Файлы обрабатываются полностью на устройстве и никуда не загружаются.

📱 Установленные приложения

Приложение читает список установленных приложений и запрашиваемые ими разрешения для формирования отчёта аудита безопасности. Эти данные остаются на вашем устройстве.

🔔 Уведомления (необязательно)

Если вы предоставите доступ к уведомлениям, SubAssist читает приложение-отправитель, заголовок и текст каждого входящего уведомления. Это происходит только в памяти устройства — чтобы сопоставить их со встроенным списком приложений и ключевых слов, связанных с подписками. Содержимое уведомлений не сохраняется и не передаётся.

⏱ Статистика использования (необязательно)

С вашего разрешения приложение читает Android UsageStats, чтобы показывать сводки экранного времени. Эти данные только отображаются вам и не покидают устройство.

🤖 Поставщик ИИ (необязательно)

Если вы выбираете облачного поставщика ИИ (Gemini, Claude, OpenRouter), ваши сообщения в чате отправляются в API этого поставщика. Чтобы давать советы с учётом устройства, запрос также содержит краткую сводку о состоянии устройства: модель устройства, версию Android, заполненность хранилища и оперативной памяти, уровень заряда, температуру и состояние зарядки батареи, а также количество установленных приложений (без названий приложений, файлов и личных идентификаторов). Это происходит только после того, как вы включите «Отправка данных ИИ-провайдеру» в Настройки → Конфиденциальность и доступ, и вы можете отключить это в любой момент. Мы не храним эти сообщения на своих серверах. Ознакомьтесь с политикой конфиденциальности выбранного поставщика ИИ.

Если вы используете модель Gemma на устройстве, данные никуда не отправляются.

⬇️ Загрузка модели на устройство (необязательно)

Если вы выбираете модель Gemma на устройстве, приложение скачивает файл модели с huggingface.co. Hugging Face получает ваш IP-адрес и технические данные запроса, а токен доступа — только если вы ввели его для закрытых моделей. Во время загрузки сообщения чата и данные устройства не отправляются; после загрузки модель работает полностью офлайн.

🛡️ Fraud Shield — проверка QR-кодов и ссылок

Когда вы сканируете QR-код, приложение проверяет ссылку локальными эвристиками и, если настроено, через Google Safe Browsing API, чтобы выявить вредоносные или фишинговые ссылки. Отсканированная ссылка отправляется в Google для проверки; никакие другие данные (идентификаторы устройства, личная информация) не передаются. Результаты сканирования хранятся локально на вашем устройстве.

📶 Fraud Shield — защита Wi-Fi (необязательно)

Если вы включите «Защита Wi-Fi сетей» в Настройках, SubAssist читает название (SSID) и идентификатор (BSSID) сети Wi-Fi, к которой вы подключены, чтобы предупредить о возможных поддельных точках доступа («evil-twin»). Для чтения этой информации Android требует разрешение на точное местоположение, однако приложение не определяет, не сохраняет и не передаёт ваши географические координаты. Функция по умолчанию выключена и работает только если вы включите её сами.

2. Данные, которые мы НЕ собираем

  • Мы не собираем личную информацию (имя, адрес электронной почты, номер телефона)
  • Мы не используем рекламные SDK и аналитические трекеры
  • Мы не продаём ваши данные. Данные передаются третьим сторонам только выбранным или включённым вами сервисам, как описано в разделах 1 и 5
  • Мы не храним ваши файлы и медиа ни на каких серверах
  • Мы не используем GPS и не определяем ваше географическое положение. Необязательная защита Wi-Fi читает только название и идентификатор сети Wi-Fi, а не ваши координаты (см. раздел 1)

3. Ключи API

Если вы вводите ключ API облачного поставщика ИИ, он хранится локально на вашем устройстве в закрытом хранилище приложения и шифруется алгоритмом AES-256-GCM с ключом, который находится в Android Keystore. Он отправляется только тому поставщику, которому принадлежит, по HTTPS, и никогда не передаётся на серверы SubSave Studio.

4. Объяснение разрешений

  • READ_MEDIA_IMAGES / READ_MEDIA_VIDEO / READ_MEDIA_AUDIO / READ_EXTERNAL_STORAGE (Android 12 и ниже) / WRITE_EXTERNAL_STORAGE (Android 10 и ниже) — аудит хранилища: просмотр названий, размеров и дат файлов для поиска дубликатов и крупных файлов
  • PACKAGE_USAGE_STATS — статистика экранного времени (пользователь предоставляет вручную)
  • BIND_NOTIFICATION_LISTENER_SERVICE — определение подписок по уведомлениям (необязательно)
  • INTERNET / ACCESS_NETWORK_STATE — облачные поставщики ИИ, Google Safe Browsing и загрузка модели на устройство
  • POST_NOTIFICATIONS — локальные уведомления, например о появлении приложения SubSave на вашем устройстве (только если вы попросили уведомить)
  • RECEIVE_BOOT_COMPLETED — восстанавливает этот необязательный запрос на уведомление после перезагрузки устройства
  • CAMERA — сканирование QR-кодов в Fraud Shield
  • ACCESS_WIFI_STATE — защита Wi-Fi в Fraud Shield (необязательно)
  • ACCESS_FINE_LOCATION / ACCESS_COARSE_LOCATION — требуется Android для чтения названия сети Wi-Fi в необязательной защите Fraud Shield; не используется для определения вашего местоположения (пользователь включает вручную в Настройках)

5. Сторонние сервисы

SubAssist может по вашему выбору подключаться к следующим внешним сервисам:

  • Google Gemini API
  • Anthropic Claude API
  • OpenRouter
  • Google Safe Browsing (проверка QR-кодов и ссылок в Fraud Shield)
  • Hugging Face (однократная загрузка модели Gemma на устройство)

Подключения к поставщикам ИИ происходят только когда вы отправляете сообщение в чате с ИИ. Safe Browsing используется при сканировании QR-кода, а Hugging Face — только при загрузке модели.

6. Хранение, защита и удаление данных

Всё, что хранит SubAssist (настройки, история сканирований, известные сети Wi-Fi, зашифрованный ключ API и загруженная модель), остаётся в закрытом хранилище приложения на вашем устройстве. Мы не храним копий и не используем учётные записи. Вы можете удалить всё это в любой момент, очистив хранилище приложения в Настройки Android → Приложения → SubAssist, или удалив приложение. Сетевые запросы выполняются по HTTPS. Сообщения, уже отправленные поставщику ИИ, хранятся у этого поставщика по его собственной политике, и мы не можем удалить их за вас.

7. Конфиденциальность детей

SubAssist не предназначено для детей младше 13 лет. Мы не собираем намеренно информацию о детях.

8. Изменения в этой политике

Мы можем время от времени обновлять эту политику. Актуальная версия всегда доступна по этому адресу. Продолжение использования приложения после изменений означает согласие с ними.
